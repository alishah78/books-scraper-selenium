# Books Scraper (Selenium)

This project scrapes book data from books.toscrape.com using 
Selenium for browser automation.

## Tools Used
- Python
- Selenium (browser automation)
- Pandas
- OpenPyXL

## Features
- Real browser automation using Chrome
- Handles JavaScript-rendered content
- Exports data to Excel with bold formatted headers
- Removes duplicate entries

## Note
This project demonstrates the ability to scrape dynamic, 
JavaScript-heavy websites where traditional scraping tools 
(like BeautifulSoup) may not be sufficient.
